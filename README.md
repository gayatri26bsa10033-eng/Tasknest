# Tasknest
A simple Python TO-DO List project to manage daily tasks.

## ABOUT
Tasknest is a beginner-friendly TO-DO List application made using Python.
It allows user to add tasks as completed, delete tasks, and check their progress.
I created this project while learning Python and practicing basic programming concepts.

## Features✨
- Add tasks
- View tasks
- Set task priority(High/Medium/Low)
- Mark tasks as completed
- Delete tasks
- Check progress and completion percentage
- Handles invalid outputs

## Built with
- Python
- Lists and dictionaries
- Loops
- Conditional statements
- Exception Handling

## How to run▶️
When the program starts, it displays a menu with six options :
1. Add Task
2. View Tasks
3. Mark Task as completed
4. Delete Task
5. Progress check
6. Exit
The user can select an option and manage their tasks through the command-line interface.

 While making this project, I practiced working with lists, dictionaries, loops, conditions, user input, and error handling.
